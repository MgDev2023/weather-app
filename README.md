# Weather App

A simple weather app that shows the current weather for any city you search.

---

## What does it do?

You type a city name and it shows you:
- Current temperature
- Weather condition (sunny, cloudy, rainy, etc.)
- Other basic weather details

---

## Tech used

- HTML
- CSS
- JavaScript
- Weather API (to fetch live weather data)

---

## How to run it

Just open `index.html` in your browser. No installation needed.

---

## Files

```
weather-app/
```
